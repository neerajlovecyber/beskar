# Built-in wallpapers

Copied (and resized to at most 3840 px wide) from the iNiR project's `assets/wallpapers/`
(https://github.com/snowarch/iNiR, GPL-3.0). Artwork credit belongs to the original artists; the files
keep the iNiR naming in `cloned_repos/inir/assets/wallpapers/`.

`shell/start.sh` copies these to `~/.local/share/beskar/wallpapers/`, where the picker (Super+W) finds them.
